## Overview

**KrishiSetu** is a comprehensive agricultural supply chain management system that leverages **blockchain technology** to ensure transparency, traceability, and trust from farm to table. By integrating AI-driven insights and a user-friendly interface, we empower farmers, distributors, and consumers to participate in a fair and improved ecosystem.

## Key Features

- **Immutable Records**: Complete transparency using Ethereum blockchain.
- **QR Code Tracking**: Instant product verification for consumers.
- **AI Advisory**: Smart insights for better decision-making.
- **Multi-Stakeholder Platform**: Seamless connection between Farmers, Distributors, Retailers, and Consumers.
- **Fair Pricing**: Eliminating middlemen manipulation.

## Quick Start

Visit the live application: **[https://sih-agro-chain.web.app](https://sih-agro-chain.web.app)**

1. **Sign Up/Login**: Create an account as a Farmer, Distributor, Retailer, or Customer.
2. **Dashboard**: Access role-specific features.
3. **Register/Scan**: Farmers register crops; Consumers scan QR codes to view the journey.
